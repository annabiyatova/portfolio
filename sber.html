Исследования и ключевые решения

Начали с интервью с бизнес-заказчиком и владельцем продукта: зафиксировали требования и ресурсы. Затем провели глубинные интервью с пользователями разных сегментов ММБ. Получили ряд важных инсайтов, на основе которых были приняты ключевые решения. Например:

Инсайт 1

Многие клиенты негативно реагируют на сравнение себя с конкурентами либо находят предлагаемых нами конкуретнов нерелевантными.

Решение

Клиенты будут лучше реагировать на сравнение с рынком, если сделать его опциональным (дать возможность включения/ отключения).

Инсайт 2

Клиентам интересны отраслевые новости.

Решение

Средняя длительность сессии увеличится, если добавить в сервис сценарий вывода важных событий в отрасли, релевантной клиенту.

Инсайт 3

Для многих клиентов в выводе аналитических данных для сравнения критически важна сезонность.

Решение

Аналитика станет более релевантной, если дать клиенту возможность выбирать период для сравнения показателей.

Продуктовые компоненты

Для реализации ключевых решений было недостаточно стандартных платформенных компонентов дизайн-системы. Например, не хватало инструментов для визуализации данных (графики с выделенным периодом времени, со средней линией), брендированных островов, островов с внутренним скроллом. Разработали собственные механики и дизайн-компоненты под них отдельно для веба и мобильного приложения, прошли ревью комиссии со стороны дизайн-системы и канала СберБизнес. Компоненты были добавлены в дизайн-систему и их стали активно переиспользовать другие продукты внутри СберБизнеса.

Гипотезы и роадмап

Гипотезы проверяли на быстрых прототипах с клиентами. Согласовали концепцию с бизнесом, а роадмап с разработкой. Чтобы уложиться в сроки, было решено вести разработку итеративно, начиная с версии mvp1 (5 месяцев). Также было принято решение вести процесс согласований дизайна и написания аналитики параллельно. Данные решения позволили выпустить запланированную функциональность в срок.
